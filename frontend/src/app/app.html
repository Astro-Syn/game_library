Game Library

A full-stack game library application where you can search for games, add them to your personal library, track their status, rate them, favorite them, and write personal notes.

Built with:

  • Angular
  • Python + FastAPI
  • PostgreSQL
  • SQLAlchemy
  • RAWG Video Games API
